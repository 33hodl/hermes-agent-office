# Design Brief — Theme 2: "Nous" (Hermes / Nous Research aesthetic)

> Sources: hermes-agent.nousresearch.com, portal.nousresearch.com, Hermes badge art, NousResearch X media (dither art, halftone textures).

## Look & feel
- **Premium dark, cyberpunk-adjacent, retro-futuristic** — the opposite of the pastel office. Thin, technical, high-contrast; evokes lo-fi / Ghost in the Shell vibes.
- **Key motifs**: halftone/stipple dots, hatching lines, dither textures, subtle scanlines, the Nous "hand" mark, the Hermes mascot (anime girl with large headphones, duotone cobalt/white).
- Perspective: same isometric world, but rendered as a **dark digital plane** — neon-edged tiles, holographic stations.

## Palette
- Background: near-black `#0a0a0f` / `#111118`
- Floor tiles: dark graphite `#181820` with cobalt grid lines `#3b6ef5`
- Primary accent: **electric/cobalt blue** `#3b6ef5` (badge blue), secondary cyan `#6ee7f7`
- Text: white `#f5f5f7`, dimmed `#8a8a99`
- UI cards: `#14141c` with 1px cobalt/30 borders, halftone corner textures
- Characters: glowing white/cobalt bean silhouettes with headphone motif, emissive outlines
- Type: monospace for labels (terminal heritage), clean sans for body

## Layout
- Same station structure as Theme 1 (desks → tools → mailbox → lounge) but stations are **terminals**: "T1..Tn" workstations, a "Tool Gateway" station, a "Mail" terminal, a "Model Router" arch
- Floor shows a faint grid + coordinate readouts (terminal vibes)
- Props: glowing portals instead of plants; holographic screens

## UI elements
- Panels: dark glass cards, mono uppercase labels ("HERMES AGENTS", "1 ACTIVE"), status text in cyan
- Metrics panel: token counters with mono numerals
- Mail widget: cobalt accent, hand-mark icon
- Agent modal: duotone avatar (blue/white), status pill, activity plan as a terminal progress list, loadout as tool chips
- Delivery toast: "// new message from <agent>" — terminal log styling

## Easter eggs
- The Hermes hand mark on the entrance
- Headphone-wearing agent avatar option
- Dither/noise texture overlay at low opacity
